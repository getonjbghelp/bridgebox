# Zapret для BridgeBox

Здесь лежит вендоренный [Flowseal zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
1.10.0 (движок — [bol-van](https://github.com/bol-van/zapret), WinDivert —
basil00). См. `../CREDITS.md`.

## Структура

Оригинальная папка `bin\` у Flowseal здесь **распакована прямо в корень** —
`.bat`-файлы указывают `BIN` на корень zapret, а не на `bin\`.

```
zapret/
  winws.exe                        движок DPI-десинхронизации
  WinDivert.dll  WinDivert64.sys   перехват пакетов (нужны права администратора)
  cygwin1.dll                      winws.exe собран под Cygwin
  stun.bin  stun2.bin              STUN-приманки
  tls_clienthello_*.bin            перехваченные ClientHello под конкретный SNI
  quic_initial_www_google_com.bin  QUIC Initial-приманка
  ver.installed.txt                отметка происхождения (версия / кто собрал)
  lists/
    list-jackbox.txt               единственный список хостов; используют все стратегии
  strategies/
    General.bat  Alternative 1-13.bat  General (EXP).bat
    Fake TLS Auto*.bat  Simple Fake*.bat        адаптированные файлы
```

22 неизменённых оригинала Flowseal раньше лежали в
`strategies/originalstrategies/` как эталон для сверки во время адаптации.
Их удалили, когда портирование было закончено — при необходимости вернуть
можно так: `git show e7eab7b^:zapret/strategies/originalstrategies/general.bat`
(или любой соседний файл).

## Конфиг

```yaml
zapret:
  enabled: true
  dir: zapret          # относительно корня проекта
  strategy: general    # slug .bat-файла из strategies/ (имя файла в нижнем регистре, не буквы/цифры -> "-")
  hide_console: true   # по умолчанию; собственную консоль winws скрывает, пока не выключено в Настройках
```

Ключа `binary:` нет — `winws.exe` находится через `dir`.

## Стратегии

Выбираются в Настройках («Стратегия»), сгруппированы **Основная / Альтернативы /
Прочие** функцией `group_strategies()`. «Тест стратегий» переключает zapret на
каждую стратегию по очереди и замеряет запрос к набору целей, выбранному над
кнопкой запуска — **Ecast** (`ecast.jackboxgames.com`,
`ecast-prod-use2.jackboxgames.com` и т.п.), **Blobcast**
(`blobcast.jackboxgames.com`) или **Оба** — это два полных прохода по всем
стратегиям подряд, а не один проход по объединённым целям: стратегия, которая
помогает одному протоколу и мешает другому, остаётся видна как две отдельные
строки, а не усредняется в одну (см. докстринг `Api.test_strategies` в
`backend/bridgebox/desktop.py`, ныне вынесенный в `api/zapret.py`). Результаты
можно экспортировать в JSON или HTML прямо из того же окна. Группа «Прочие» по
умолчанию пропускается — Fake TLS Auto / Simple Fake медленно проверяются.

То, что часть стратегий не проходит тест — это **нормальный результат**, а не
ошибка. Профиль, который не пробивается до Jackbox — тоже результат, просто
отрицательный.

Домены берутся **только** из `lists/list-jackbox.txt` через `--hostlist=`. Ни
в одном адаптированном `.bat` нет встроенного `--hostlist-domains` — правится
список, а не сам `.bat`.

Редактируется из Настроек («Сеть» → «Домены для обхода»), правка проверяется на
границе и записывается атомарно: winws не отклоняет некорректную строку, а
молча её игнорирует, поэтому плохая запись иначе всплыла бы как «zapret ничего
не обошёл» при следующем запуске моста, далеко от места правки, которая это
вызвала. Список сейчас покрывает 17 официальных хостов Jackbox (Ecast, Blobcast
и общие/CDN-хосты вместе). Неофициальные зеркала (`jackbox.fun` и подобные) по
умолчанию **не включены** — при необходимости добавляются сюда же вручную, см.
раздел с решением проблем в корневом `README.md`, почему их убрали.

### Порт 38203 — сессия Blobcast поверх socket.io

Каждая из адаптированных стратегий несёт `38203` **и** в `--wf-tcp`, **и** в
`--filter-tcp`, рядом с 80/443. Это не порт моста — это порт, на котором сама
Blobcast-игра открывает свою долгоживущую socket.io-сессию, найден перехватом
пакетов (см. докстринг модуля `server/blobcast.py`). Он обязан быть в обоих
фильтрах, иначе эта сессия вообще не получает обход DPI: по замерам первое
подключение через неё проходило, а каждое повторное таймаутилось — именно так
выглядела нестабильная долгая Blobcast-сессия до того, как это добавили.

Если порт когда-нибудь поменяют для неофициального Blobcast-сервера (Настройки
→ Профили подключения → профиль Blobcast → «Порт socket.io»), новый порт нужно
так же добавить во все стратегии — иначе этот профиль молча теряет обход.
`test_blobcast_port_is_in_the_dpi_filters` сверяет номер порта с
`SOCKETIO_PORT` из `server/blobcast.py`, чтобы расхождение падало громко.

### Устаревшие имена

Старые ключи конфига, которые всё ещё резолвятся:

- `general-alt11` → `Alternative 11.bat`

Алиас, чья цель отсутствует в `strategies/`, хуже, чем отсутствие алиаса —
он превращает «неизвестная стратегия» в ошибку с именем файла, которого
никогда не было в поставке. `test_strategy_assets.py` проверяет, что каждый
алиас резолвится.

## Что адаптация изменила и что выбросила

Каждый адаптированный файл соответствует 1:1 оригиналу Flowseal (раньше в
`strategies/originalstrategies/`, имя оригинала указано в шапке каждого
файла). Три вещи пришлось изменить — всё вынуждено структурой:

1. **Нет `service.bat`.** Оригиналы четыре раза вызывают `call service.bat` за
   обновлениями и заполнением `%GameFilterTCP%` / `%GameFilterUDP%`. Без него
   эти переменные разворачиваются в пустоту и дают битый `--wf-tcp=…,`.
2. **Нет `start /min`.** Оригиналы запускают winws в отдельном окне; BridgeBox
   отслеживает PID, а отсоединённый запуск отдал бы ему PID запускающего
   батника, а не самого winws. Все адаптированные файлы запускают winws **в
   текущем окне** (foreground).
3. **Выжили только 2 профиля из 9.** Оригиналы несут девять секций `--new`:
   голос Discord по UDP, `discord.media`, Google, catch-all `ipset-all` и
   игровые диапазоны `%GameFilter*%` — **ни один не относится к Jackbox**. Два
   актуальных (TCP 80,443 и QUIC/UDP 443) перенесены. Выброшенные секции ещё и
   требовали 12 файлов, которых здесь никогда не было — прежде всего
   `tls_clienthello_www_google_com.bin`, `list-general.txt`, `ipset-all.txt` и
   пары `list-exclude*` / `ipset-exclude*`.

Как следствие, из всех файлов пропали флаги `--hostlist-exclude`, `--ipset`,
`--ipset-exclude`, `--filter-l7`, `--ip-id`, `--dpi-desync-cutoff` и
`--dpi-desync-any-protocol`. Это осознанно: при таком маленьком списке хостов
(официальные домены Jackbox, без зеркал) исключать попросту нечего.

Восстановить *выброшенные* профили (голос Discord, `discord.media`, Google,
catch-all `ipset-all`, `%GameFilter*%`) из этого репозитория нельзя — оригиналы
были только `.bat`-файлами, а ресурсы, на которые они ссылаются (`.bin`-пейлоады,
`list-general.txt`, файлы `ipset-*`), сюда никогда не завозились. Это другая
задача, отличная от адаптации незнакомой репозиторию стратегии — см. «Адаптация
новой стратегии» ниже.

## Не кладите сюда «сырой» оригинал Flowseal без изменений

Он не заработает — по причинам 1–3 выше. Вместо этого перенесите вызов winws в
уже существующую преамбулу (проверки на `winws.exe` и список хостов, `BIN`/`LISTS`,
указывающие на эту папку, запуск в текущем окне).

`test_strategy_assets.py` проверяет обе стороны: что каждый файл, который
стратегия называет через `%BIN%`, существует, и что каждый `.bin` на диске
кем-то используется. Именно вторая проверка важна — три стратегии когда-то
незаметно подставили `tls_clienthello_max_ru.bin` вместо файла, который называл
их оригинал, оставив `stun2.bin` и `tls_clienthello_4pda_to.bin` мёртвым грузом
на диске.

## Адаптация новой стратегии

`backend/bridgebox/zapret/strategy_adapt.py` автоматизирует то, что раньше
делалось руками при портировании: получив на входе «сырой» `general*.bat` от
Flowseal, которого репозиторий раньше не видел, выбирает два относящихся к
Jackbox профиля и рендерит их в собственный шаблон BridgeBox — тот же отбор,
что описан выше в разделе «Что адаптация изменила», только программно, а не
чтением каждого файла руками.

Это **генератор по белому списку токенов, а не текстовый трансформер.** `.bat`,
собранный из скачанного текста и затем запускаемый от администратора — прямой
путь к command injection, поэтому исходный текст никогда не копируется и не
выполняется как есть: он разбирается на токены `--flag=value`, и в рендер
попадают только флаги `dpi-desync*`, чьё значение соответствует строгому
набору символов (или форме `%BIN%<безопасное-имя>.bin`). Правило отбора,
выверенное по всем 22 уже поставленным адаптациям, а не придуманное: TCP-профиль,
чей `--filter-tcp` покрывает и 80, и 443, и QUIC-профиль с
`--dpi-desync-fake-quic`, оба предпочитающие `--hostlist` вместо `--ipset`.
Стратегия без одного из этих профилей или называющая `.bin`-пейлоад, который
не поставлялся вместе с ней, пропускается с указанием причины, а не
записывается наполовину рабочей.

Golden-тест (`backend/tests/test_strategy_adapt.py`, фикстуры в
`backend/tests/fixtures/flowseal-1.10/originalstrategies/`, восстановить можно
через `git show e7eab7b^:zapret/strategies/originalstrategies/<имя>`)
проверяет, что адаптер воспроизводит флаги всех поставленных файлов один в
один. Уже существующую адаптацию, сделанную вручную, это никогда не
перезаписывает — новый файл получает только квалификатор, которого ещё нет в
`strategies/`.

## Обновление вендоренных бинарников

`backend/bridgebox/zapret/update.py` проверяет релизы Flowseal на GitHub и
может заменить `winws.exe`, `WinDivert*`, `cygwin1.dll` и `.bin`-пейлоады — из
Настроек → «Обновление Zapret». Привязан к `Flowseal/zapret-discord-youtube` и
к `github.com`/`objects.githubusercontent.com` после редиректов; скачанный
архив ограничен по размеру и числу элементов, а `winws.exe` проверяется на
PE-заголовок (`MZ`) до применения — это источник кода, который потом
запускается с повышенными правами.

Устанавливаются только пейлоады, на которые реально ссылается какая-то из
адаптированных стратегий (`select_for_install`) — релиз несёт пейлоады для
профилей, которые BridgeBox никогда не портировал (Discord, Steam, Tencent,
диапазоны игровых портов), и копирование их без ссылок — именно то состояние,
которое запрещает `test_every_payload_file_is_used_by_some_strategy`. **Файлы
стратегий `.bat` этим путём никогда не трогаются** — почему, см. «Не кладите
сюда сырой оригинал Flowseal без изменений» выше.

## Заметки

- При `zapret.enabled: true` BridgeBox запрашивает **UAC** при запуске
  (WinDivert должен загрузить драйвер уровня ядра).
- Остановка убивает **только то дерево процессов, которое запустил сам
  BridgeBox**, и только если это сделала текущая сессия:
  `taskkill /F /T /PID <pid>`. `/T` не опционален — отслеживаемый PID это
  `cmd.exe`, хостящий `.bat` стратегии, а `winws.exe` — его дочерний процесс,
  так что убийство одного PID оставило бы winws работать с открытым хендлом
  WinDivert. winws, запущенный пользователем вручную, или оставшийся от
  прошлой сессии BridgeBox, намеренно не трогается.
- Общесистемный `taskkill /F /IM winws.exe` всё ещё существует как
  `process.kill_all_winws()`, с ровно одним оправданным вызывающим —
  обновлятором, который вот-вот перезапишет `winws.exe` и `WinDivert64.sys` и
  не может продолжить, пока их держит открытым хоть один процесс.
